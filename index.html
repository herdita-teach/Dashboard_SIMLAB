Panel Admin

Hanya admin yang dapat mengunggah file data. Pengguna lain cukup melihat dashboard.

1. Unggah file Monitoring Order SIMLAB (.xlsx)

Seret file .xlsx ke sini atau
Format sama dengan template (baris judul "MONITORING ORDER", header kolom No Order, Status Order, dst.). Setiap file disimpan sebagai satu "upload" untuk dibandingkan.

2. Daftar upload

3. Nama status & status selesai proses

File SIMLAB hanya berisi kode status. Isi nama tiap kode agar tampil di dashboard. Centang kode yang dianggap selesai proses (dipakai untuk menghitung order dalam proses dan keterlambatan).

4. Bagikan ke pengguna lain

Data tersimpan di browser komputer ini. Agar pengguna lain melihat data terbaru, unduh dashboard versi terbaru lalu taruh di folder bersama / kirim ke tim. Data di dalam file tersebut dienkripsi (AES-256) dan hanya bisa dibuka dengan kata sandi buka dashboard yang Anda tentukan saat mengunduh.
